# How to Play a Text Adventure / MUD

Imagine you are inside a story.

The game tells you what you see, and you tell the game what you want to do.

There are usually four things in the world:

- **Rooms** - places you can be
- **Objects** - things you can examine or use
- **Characters** - people, creatures, robots, NPCs
- **Exits&& - ways to move to other rooms

A typical room description might look like:
```
Forest Clearing

You are standing in a small clearing.
A path leads north.
A large oak tree stands here.

You see:
  old lantern
  squirrel
```

## Rule #1: Read Carefully

Most clues are hidden in descriptions.

If the game says:
```
The lantern seems unusually heavy.
```

that's probably not just decoration.

In adventure games, unusual details are often clues.

## Rule #2: Look Around Constantly

Useful commands are often:
```
look
l
```

or
```
look tree
look lantern
examine lantern
```

When stuck, look at everything.

## Rule #3: Try Talking

When you meet a character, don't assume they are decoration.

Try things like:
```
talk guard
ask guard
say hello
```

Sometimes the game gives important hints through conversation.

## Rule #4: Explore

Movement is usually done with directions:
```
north
south
east
west
up
down
```

or shortcuts:
```
n
s
e
w
u
d
```

A common beginner mistake is staying in one room too long.

If nothing works, explore somewhere else.

## Rule #5: Pick Things Up

If you see something useful:
```
get lantern
take lantern
```

Then check your inventory:
```
inventory
inv
i
```

Many puzzles require carrying an item from one place to another.

## Rule #6: Experiment

Text adventures reward curiosity.

Try:
```
open chest
push button
pull lever
climb tree
read sign
unlock door
light lantern
```

Even if you're not sure.

Many solutions are discovered by trying things.

## Rule #7: Most Puzzles Follow Simple Logic

If you find:
```
key
```

and later:
```
locked door
```

try:
```
unlock door with key
```

Think:
```
"What would I do if I were really there?"
```

That solves many puzzles.

## Rule #8: Strange Details Matter

If a description says:
```
One brick looks newer than the others.
```

that brick is probably important.

Game designers rarely mention unusual details by accident.

## Rule #9: When Stuck, Make a List

Ask:
```
Where can I go?
What items do I have?
Who can I talk to?
What unusual things have I seen?
```

The answer is often hidden among those four.

## Rule #10: There Is No Penalty for Looking Silly

Many players succeed by trying ridiculous ideas:
```
look under bed

push statue

listen at door

smell flower
```

Sometimes the weird idea is exactly right.

## A Beginner's Puzzle-Solving Formula

Whenever you're stuck:
```
LOOK
TALK
TAKE
EXPLORE
THINK
TRY
```

1. Look carefully.
2. Talk to characters.
3. Take useful objects.
4. Explore new rooms.
5. Think about the clues.
6. Try an idea.

Repeat until something changes.

## Most Important Secret

New players often think:

> "I need to guess what the author wants."


Experienced players think:

> "I need to pay attention to the world."


The game is usually trying to tell you the answer. The clues are often already visible. Your job is mostly to notice them.

And one final piece of advice specifically for your grandson:

> Treat the game like investigating a mystery. Keep asking, "What here seems unusual?" The unusual thing is very often the next clue.

That mindset alone is probably responsible for half of all successful adventure-game puzzle solving.
